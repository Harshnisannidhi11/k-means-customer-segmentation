
# K-Means Customer Segmentation

## Project Overview
This project focuses on customer segmentation using the K-Means Clustering algorithm. The goal is to group customers based on their characteristics and spending behavior to identify meaningful customer segments.

## Objectives
- Analyze customer data to identify patterns.
- Apply K-Means clustering for customer segmentation.
- Understand customer groups based on income and spending behavior.
- Visualize the identified customer segments.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The project uses the Mall Customers dataset (`Mall_Customers.csv`), containing customer information such as age, annual income, and spending score.

## Project Workflow
1. Data loading and exploration
2. Data preprocessing
3. Exploratory Data Analysis
4. Applying K-Means Clustering
5. Identifying customer segments
6. Visualizing clustering results

## Repository Structure
- `Customer_Segmentation_Project.ipynb` – Project implementation
- `Mall_Customers.csv` – Dataset used for analysis

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the cells sequentially to explore the analysis and results.

## Outcome
Applied unsupervised machine learning techniques to segment customers and explore patterns in customer purchasing behavior.
